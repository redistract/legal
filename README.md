# Redistract legal pages

Privacy Policy, Terms of Use and data-deletion instructions for the Redistract Android app, served at https://redistract.github.io/legal/.

These files are generated. Edit the sources in the app repository (`app/src/main/assets/legal/*.md`, `legal-site/src/`) and run `python tools/build_legal_site.py`, then copy `legal-site/public/` here.
